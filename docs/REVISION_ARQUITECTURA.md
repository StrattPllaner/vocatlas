# Arquitectura: tarjetas que necesitan revisión antes de publicarse

**Total:** 29 tarjetas para un arquitecto, 5 para confirmar en fuente oficial y 7 cifras pendientes.

Este archivo se genera del catálogo (`datos/carreras/arquitectura.json`). Cada tarjeta marcada con `revisar` aparece aquí con su texto completo.

- **Para un arquitecto:** afirmaciones sobre la carrera o sobre cómo se ejerce la profesión. La pregunta para quien revise es: ¿esto es correcto y no le enseña nada equivocado a un estudiante de prepa?
- **Para confirmar en fuente oficial:** reglas, trámites o etapas (admisión, cédula, requisitos). Se confirman en la convocatoria, el plan de estudios o la autoridad correspondiente, no con una opinión.
